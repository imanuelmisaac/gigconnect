# **App Name**: GigConnect

## Core Features:

- Homepage Display: Displays the application's title and navigation buttons for login and registration.
- User Registration: Allows new users to create an account and stores their credentials for future access.
- User Login: Enables existing users to securely log into their accounts using their credentials.
- Basic Routing: Handles navigation between the homepage, login page, and registration page.

## Style Guidelines:

- Primary color: A deep, trustworthy blue (#294D8A) to evoke professionalism and stability, suitable for key actions and branding elements.
- Background color: A very light, almost white tone with a subtle hint of the primary hue (#F2F4F7), ensuring a clean and spacious feel while maintaining consistency.
- Accent color: A vibrant, clear cyan-blue (#3EB0D4), used sparingly to highlight interactive elements like calls-to-action and important notifications, offering a refreshing contrast.
- All text will use 'Inter', a versatile sans-serif font known for its legibility and modern, neutral aesthetic, fitting for both headlines and body text.
- Use clean, minimalistic line-based icons for a modern and uncluttered user interface.
- Employ a responsive, card-based layout on desktop, transitioning to a stacked, single-column layout on mobile, prioritizing content visibility.
- Subtle fade-in and slide-up animations for content loading, ensuring a smooth and pleasant user experience without distraction.
